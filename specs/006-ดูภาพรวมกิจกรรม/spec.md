# Feature: ดูภาพรวมกิจกรรม (Activity Overview Dashboard)
Spec ID: SPEC-DSH-006 | Source: UC-06 (Use Case Table) | Use case: UC-06
Owner: ทีม A | Status: Draft v1 | Updated: 2569-09-19

## Goal
อาจารย์ที่ปรึกษาสโมสรเห็นภาพรวมกิจกรรมทั้งเทอมของสโมสรที่ดูแล ผ่านหน้า Dashboard
ทั้งจำนวนกิจกรรมแยกตามสถานะ และกราฟสัดส่วนกิจกรรมตามกลุ่มทักษะ/ตัวชี้วัด เพื่อให้ทราบว่า
กิจกรรมตอบตัวชี้วัดจริงหรือไม่ โดยไม่ต้องขอรายงานจากกรรมการสโมสรเอง

## Scope
### In scope
- แสดงหน้า Dashboard สรุปกิจกรรมทั้งเทอมของสโมสรที่อาจารย์ดูแล
- แสดงจำนวนกิจกรรมแยกตามสถานะ
- แสดงกราฟสัดส่วนกิจกรรมตามกลุ่มทักษะ/ตัวชี้วัด
### Out of scope
- การสร้าง / แก้ไข / อนุมัติเอกสารโครงการ (UC-01, UC-03, UC-05)
- เข้าสู่ระบบ / ยืนยันตัวตน (UC-09) - ถือว่าทำสำเร็จแล้วก่อนเข้าฟีเจอร์นี้ (precondition)
- การ export หรือพิมพ์รายงาน (ไม่ได้ระบุในตาราง)
- การดูรายละเอียดเจาะลึกรายกิจกรรมจาก Dashboard (ไม่มีใน Main Flow - อาจเป็น use case แยก)

## Constraints
- CON-NFR-21 ต้องยืนยันตัวตน (Login) ก่อนใช้งานฟีเจอร์นี้ทุกครั้ง
- DOM-SCOPE-01 อาจารย์ต้องเห็นเฉพาะข้อมูลกิจกรรมของสโมสรที่ตนดูแลเท่านั้น (อนุมานจาก "สโมสรที่ดูแล"
  ในคำอธิบาย - ตารางไม่ได้ระบุ constraint นี้ไว้ตรง ๆ ดู Q-01)

## Requirements
- FR-DSH-01 เมื่ออาจารย์เปิดหน้า Dashboard ระบบต้องแสดงจำนวนกิจกรรมแยกตามสถานะของสโมสรที่อาจารย์ดูแล
                                                                        <- UC-06 Main Flow ขั้น 1-2
- FR-DSH-02 ระบบต้องแสดงกราฟสัดส่วนกิจกรรมตามกลุ่มทักษะ/ตัวชี้วัด
                                                                        <- UC-06 Main Flow ขั้น 3
- FR-DSH-03 ข้อมูลจำนวนกิจกรรมและกราฟที่แสดงต้องตรงกับข้อมูลกิจกรรมจริงในระบบ ณ เวลาที่เปิดดู
                                                                        <- UC-06 Postcondition / Acceptance Criteria

## Quality Requirements
- NFR-SEC-01 (อ้างอิง NFR ข้อ 21) ทุกการเข้าถึงหน้า Dashboard ต้องผ่านการยืนยันตัวตน (Login) ก่อน

## Acceptance Criteria
- [ ] AC-DSH-01 (FR-DSH-01, FR-DSH-02, FR-DSH-03)
      Given มีกิจกรรมที่ผ่านการอนุมัติในเทอมนี้
      When  อาจารย์เปิด Dashboard
      Then  ระบบแสดงจำนวนกิจกรรมและกราฟตัวชี้วัดถูกต้องตรงกับข้อมูลจริง
- [ ] AC-DSH-02 (FR-DSH-01)
      Given มีกิจกรรมหลายสถานะปะปนกัน (เช่น รอตรวจสอบ, อนุมัติสมบูรณ์, ตีกลับ)
      When  อาจารย์เปิด Dashboard
      Then  ระบบแสดงจำนวนกิจกรรมแยกตามแต่ละสถานะอย่างถูกต้อง
- [ ] AC-DSH-03 (FR-DSH-02)
      Given มีกิจกรรมที่จัดกลุ่มตามทักษะ/ตัวชี้วัดต่างกัน
      When  อาจารย์เปิด Dashboard
      Then  ระบบแสดงกราฟสัดส่วนกิจกรรมตามกลุ่มทักษะ/ตัวชี้วัดครบทุกกลุ่มที่มีข้อมูล
- [ ] AC-DSH-04 (NFR-SEC-01)
      Given ผู้ใช้ยังไม่ได้เข้าสู่ระบบ
      When  พยายามเข้าถึงหน้า Dashboard
      Then  ระบบปฏิเสธการเข้าถึงจนกว่าจะยืนยันตัวตนสำเร็จ

## Assumptions & Open Questions
- ASM-01 "สโมสรที่ดูแล" หมายถึงอาจารย์เห็นข้อมูลเฉพาะสโมสรที่ตนเป็นอาจารย์ที่ปรึกษาเท่านั้น
  (data scoping) แม้ตารางจะไม่ได้ระบุ constraint/exception นี้ไว้ตรง ๆ (ดู Q-01)
- ASM-02 "เทอมนี้" อ้างอิงจากปีการศึกษา/ภาคการศึกษาปัจจุบัน ณ เวลาที่เปิดดู
- Q-01 กรณีอาจารย์ดูแลหลายสโมสร Dashboard แสดงรวมทุกสโมสร หรือมีตัวเลือกกรองแยกรายสโมสร?
  ไม่มี flow ระบุการกรอง/เลือกสโมสรไว้ในตาราง
- Q-02 "กลุ่มทักษะ/ตัวชี้วัด" มีรายการคงที่กี่กลุ่ม และมาจากแหล่งเดียวกับเกณฑ์ Checklist
  ใน UC-01/UC-03 หรือไม่?
- Q-03 Dashboard นี้อนุญาตให้เลือกดูย้อนหลังเทอมก่อนหน้าได้หรือไม่ หรือแสดงเฉพาะเทอมปัจจุบันเท่านั้น
  (ตารางระบุ "ทั้งเทอม" แต่ไม่ชัดว่าเลือกเทอมอื่นได้ไหม)
- Q-04 ไม่มีการระบุเวลาตอบสนอง (performance) ของหน้า Dashboard ไว้ในตาราง -> ควรกำหนดเป้าหมาย
  เช่น p95 กี่วินาที เพื่อให้ทดสอบได้จริง

## Reflection
- คำถามของ AI ที่ทีมไม่คาดคิดคือ เรื่องการแก้ไขโครงการเดียวกันพร้อมกัน (concurrent editing)
- คำถามของเพื่อนที่ AI ไม่ถามคือ เมื่อข้อมูลจากระบบที่เชื่อมต่อกันไม่ตรงกัน ใครเป็นผู้รับผิดชอบแก้ไข
- AI ทำผิดกติกาข้อ 2 ใน plan เพราะกำหนดรายละเอียดโครงสร้างข้อมูลและ API บางส่วน ทั้งที่ Open Questions ยังไม่ปิด ทีมจึงควรตรวจทุกการตัดสินใจใน plan ให้ย้อนกลับไปอ้างอิง ID และข้อกำหนดใน spec ได้เสมอ
บทเรียนสำคัญคือทีมต้องตอบ Open Questions ให้ชัดเจนก่อนให้ AI สรุปแผนการพัฒนา

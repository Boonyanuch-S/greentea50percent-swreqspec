# เอกสารตัวอย่างสำหรับทดลองอัปโหลด

ไฟล์ในโฟลเดอร์นี้เป็นเอกสารสมมติสำหรับทดสอบระบบ ไม่ใช่เอกสารจริงของมหาวิทยาลัย โครงเอกสารอ้างอิงแบบฟอร์มจาก
https://dsa.su.ac.th/ksu/?page_id=306 ส่วนชื่อบุคคล งบประมาณ และรหัสโครงการเป็นข้อมูลสมมติ

| ไฟล์ | ใช้ตอนไหน |
|---|---|
| `เล่มโครงการ.pdf` | กรรมการแนบในหน้าสร้างโครงการ |
| `กส-002.pdf` | กรรมการแนบในหน้าสร้างโครงการ |
| `ใบแนบกิจกรรม.pdf` | กรรมการแนบในหน้าสร้างโครงการ |
| `ใบปะหน้า.pdf` | อาจารย์อัปโหลดหลังอนุมัติเนื้อหา |

สร้างใหม่ได้ด้วย `backend/scripts/build_sample_documents.py` ซึ่งต้องใช้ PyMuPDF และฟอนต์ IBM Plex Sans Thai
(ทีมเลือกเอง ไม่ได้มาจาก spec) ระบบไม่ได้ใช้ทั้งสองอย่างตอนทำงาน
